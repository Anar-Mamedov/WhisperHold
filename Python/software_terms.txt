# Built-in software vocabulary. One term per line, in the spelling that should
# appear in transcripts; "#" starts a comment. Used three ways: the decoder is
# nudged toward these spellings while it listens (contextual biasing), the
# post-correction treats them like the user's own technical terms, and the
# optional local language model may only propose replacements drawn from here
# or from the user's list. Multi-word terms are allowed.
#
# Turkish agent forms that developers actually say come last; the model needs
# the whole form for those, the root alone was measured not to be enough.
